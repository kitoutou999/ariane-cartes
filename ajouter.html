Ajouter une carte

La carte est préparée dans ton navigateur : rien n'est envoyé tant que tu ne l'as pas déposée sur GitHub.

1. La sortie

Dans Ariane : Réglages, Mes sorties, ta sortie, Préparer les exports, puis « Partager le JSON (sortie complète) ».

2. Les points GPS

Relève la position de 2 ou 3 lieux-dits à ciel ouvert (entrées, puits), le plus éloignés possible les uns des autres. Sur Google Maps : appui long à l'endroit exact, puis touche les coordonnées pour les copier.

3. Les informations

La carte publiée contient la trace, les noms des lieux-dits et le jour de la sortie, sans les heures ni les photos. Tout le monde pourra la voir.

4. Publier

Le fichier est téléchargé. Pour le publier (compte GitHub gratuit nécessaire) :

  1. Ouvrir le formulaire GitHub
  2. Glisse le fichier dans la zone « Fichier de la carte » (sur téléphone : touche la zone, puis l'icône de pièce jointe).
  3. Valide avec « Create ». La carte est vérifiée puis publiée automatiquement en une à deux minutes ; la réponse s'affiche dans le ticket.
