Ajouter une carte

La carte est préparée dans ton navigateur : rien n'est envoyé tant que tu ne l'as pas déposée sur GitHub.

Raccourci : tu peux aussi glisser directement le SVG d'Ariane dans le formulaire GitHub. Il sera publié comme plan seul, avec le titre du ticket.

1. Le plan

Dans Ariane : Réglages, Mes sorties, ta sortie, Préparer les exports, puis « Partager la carte SVG ».

2. Les informations

3. Placer sur le terrain (facultatif)

Sans point GPS, la carte est publiée comme un plan : fond sombre, nord en haut, boussole utilisable. Pour la poser aussi sur la photo aérienne, ajoute les coordonnées de 2 ou 3 lieux-dits relevés à ciel ouvert (entrées, puits), le plus éloignés possible. Sur Google Maps : appui long à l'endroit exact, puis touche les coordonnées pour les copier.

4. Publier

Le SVG est téléchargé. Pour le publier (compte GitHub gratuit nécessaire) :

  1. Ouvrir le formulaire GitHub
  2. Glisse le fichier SVG dans la zone « Plan de la carte » (sur téléphone : touche la zone, puis l'icône de pièce jointe).
  3. Valide avec « Create ». La carte est vérifiée puis publiée automatiquement en une à deux minutes ; la réponse s'affiche dans le ticket.

La carte publiée contient la trace, les noms des lieux-dits, le jour de la sortie et les points GPS saisis. Tout le monde pourra la voir.
